# Reference movies (not in git)

`3226M.fm2` is TASVideos publication [3226M](https://tasvideos.org/3226M) (any%, FCEUX, PRG0), by its authors as
credited on that page. It is not redistributed here. To use it (`lab.parse_fm2`, `tools_refsplits.py`), download the
zip from `https://tasvideos.org/3226M?handler=Download` and put the `.fm2` in this directory as `3226M.fm2`.

The corpus movie `main` (`disasm/corpus/`) replays the first 78,090 frames of its input verbatim (worlds 1-5) and
continues with input authored here; the route through those worlds is theirs.

`6389M.bk2` (and the `6389M-input-log.txt` extracted from it) is TASVideos publication
[6389M](https://tasvideos.org/6389M) (game-end glitch, BizHawk), by its author as credited there; download it from
`https://tasvideos.org/6389M?handler=Download`. Only its landmarks are used here (`../speedrun.md`).

The `*-headers.txt` files are the HTTP headers of those downloads.
